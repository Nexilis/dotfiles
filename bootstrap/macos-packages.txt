# Package manifest for the macOS bootstrap. Source of truth for what gets
# installed on a Mac; bootstrap/macos/install-group.sh reads it and
# bootstrap/justfile exposes one recipe per group.
#
# Columns, whitespace-separated:
#   group   kind   package   [# note]
#
# kind:
#   formula  brew install <package>          (tap-qualified names are fine)
#   cask     brew install --cask <package>
#   script   bash bootstrap/macos/<package>.sh   (non-brew installers)
#
# Order matters inside a group: scripts run after the brew steps of the same
# group, in manifest order.
#
# Only leaves belong here. Anything Homebrew pulls in as a dependency (ffmpeg's
# codecs, poppler's gnupg, lua under luarocks) is deliberately absent.
